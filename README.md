# Card Saints

A simple one-page site for Card Saints, an investment firm focused on the trading card market.

Built with [Next.js](https://nextjs.org) (App Router) and [Tailwind CSS](https://tailwindcss.com).

## Getting started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run start` — run the production build
- `npm run lint` — run ESLint

## Shop / One Piece TCG releases

The `/buy` page is a demonstration storefront for Japanese One Piece TCG releases
(Booster Sets `OP` and Extra Boosters `EB`) with mock inventory and a mock checkout
(no real payment is processed).

Product data and cover art are generated by a one-off script:

```bash
node scripts/fetch-assets.mjs
```

This pulls the live set list from the free [optcgapi.com](https://optcgapi.com) API,
downloads the Japanese booster-box art into `public/products/` (a public Shopify
product feed, with the official Japanese CDN as a fallback), and writes the product
catalog (prices in HKD + mock stock) to `src/lib/catalog.json`. Both outputs are
committed, so the app runs fully offline; re-run the script to refresh data or add
new sets.

Product art is © Eiichiro Oda / Shueisha, Toei Animation, Bandai Namco Entertainment;
it is used here for demonstration only.
